# 맥가이7 연동 — 학원 데스크톱에서 이어서 할 일

원장님이 "맥가이7 연동 시작하자"라고만 말하면, **이 문서를 처음부터 끝까지
그대로 따라가면 된다.** 앞뒤는 다 만들어져 있고 비어 있는 것은 딱 하나다.

## 지금 상태 한눈에

| | 상태 |
|---|---|
| DB 테이블 (`lecture_attendance`, `lecture_overrides`, `macgai_sync_log`) | ✅ 적용 완료 |
| 판정 로직 (`src/lib/lectureRules.ts`) | ✅ 테스트 포함 |
| 기록·알림·감시 (`src/lib/lectureAttendance.ts`) | ✅ |
| 강의 출결 화면 (조교·종주T) | ✅ 배포됨 |
| 크론 라우트 (`/api/cron/lecture-attendance`) | ✅ |
| GitHub Actions 스케줄 | ✅ 파일 있음 (주말 10분마다) |
| **맥가이7 화면 읽어오기 (`src/lib/macgai7.ts`)** | ❌ **이것만 비어 있음** |

`fetchTodayCheckIns()` 하나만 채우면 끝난다. 돌려줄 것은 이 배열뿐이다.

```ts
[{ studentCode: "56501", checkedInTime: "22:04" }, ...]
```

- `studentCode` — 등하원명단의 **학번** 칸. 앱 `students.student_code`와 같은 5자리.
- `checkedInTime` — **등원** 칸의 "HH:MM".

**이름·학급·전화번호는 가져오지 말 것.** 앱에 저장할 이유가 없다.

## 왜 브라우저(claude.ai/code) 세션에서 못 했나

그 환경은 외부 인터넷이 막혀 있어 `edu.macgai7.com`에 접속조차 안 된다.
로그인이 어떻게 도는지 봐야 스크래퍼를 쓸 수 있어서 이 조각만 남겼다.

## 순서

### 1. 조회 전용 계정 만들기 (원장님이 직접)

맥가이7에 **출결현황만 볼 수 있는 직원 계정**을 하나 만든다. 원장님 본인
계정을 쓰지 않는다.

### 2. 시크릿 등록 (원장님이 직접)

`MACGAI7_ID`, `MACGAI7_PASSWORD`를 **세 곳 모두**에 넣는다.

- 데스크톱의 `.env.local`
- Vercel production env
- claude.ai/code "Default" 환경

> 자격증명 입력은 자동화하지 말 것. 화면만 열어주고 원장님이 직접 입력하게 한다.

### 3. 로그인 흐름 조사 — 조사 도구를 돌린다

개발자도구를 뒤질 필요 없다. 조사 스크립트가 있다.

```bash
MACGAI7_ID=아이디 MACGAI7_PASSWORD=비번 npm run macgai:probe
```

그러면 로그인 화면의 form·숨은 필드(`__VIEWSTATE` 등)·아이디/비번 칸 이름,
로그인 성공 여부, 세션 쿠키 이름을 찍어준다. 출결현황 주소를 알면 한 번 더:

```bash
MACGAI7_ID=... MACGAI7_PASSWORD=... npm run macgai:probe -- /그/경로.aspx
```

이번엔 그 화면의 조회 파라미터, **엑셀 버튼이 부르는 주소**, 표의 머리글과
칸 수까지 나온다.

> **출력은 그대로 복사해서 종주T(AI)에게 줘도 된다.** 표의 값은 가려서
> 찍힌다 — `김민찬` → `●●●`, `010-1234-5678` → `999-9999-9999`.
> 모양만 남기고 실제 값은 안 나가게 만들어뒀다.
>
> `--save`를 붙이면 원본 HTML이 `macgai7-probe/` 에 남는데, **그 파일에는
> 학생 이름·전화번호가 그대로 들어 있으니 공유하지 말 것.**

**화면 HTML을 파싱하기보다 "엑셀" 버튼이 부르는 요청을 그대로 쓰는 쪽이
낫다.** 마크업보다 훨씬 덜 바뀐다.

### 3-b. 데스크톱 말고 여기서 하려면

claude.ai/code 환경의 **네트워크 정책**에서 `edu.macgai7.com`을 허용하면
브라우저 세션에서도 조사·구현을 끝까지 할 수 있다. 지금은 막혀 있어서
CONNECT가 403으로 끊긴다(`curl "$HTTPS_PROXY/__agentproxy/status"` 로 확인
가능). 정책은 환경을 만든 사람이 바꾼다 —
<https://code.claude.com/docs/en/claude-code-on-the-web> 참고.

### 4. `src/lib/macgai7.ts` 채우기

파일에 주석으로 할 일이 적혀 있다. `fetchTodayCheckIns()`만 구현하면 된다.
실패하면 던지면 된다 — 크론이 잡아서 `macgai_sync_log`에 남긴다.

### 5. 로컬에서 확인

```bash
npm run dev
# 다른 터미널에서
curl -H "Authorization: Bearer $CRON_SECRET" http://localhost:3000/api/cron/lecture-attendance
```

로컬에서는 **미출석 알림이 실제로 안 나가고 콘솔에만 찍힌다**
(`isDeployedEnvironment()`). 운영 DB를 그대로 보기 때문에 넣어둔
안전장치다. **지우지 말 것.**

### 6. 배포하고 주말에 지켜보기

배포 후 첫 주말에 확인할 것:

- `macgai_sync_log`에 `ok=true`가 10분마다 쌓이는지
- 강의 출결 화면에 자동으로 출결이 채워지는지
- 안 온 학생이 제대로 결석으로 잡히는지
- **엉뚱한 학생이 결석으로 잡히지는 않는지** ← 제일 중요

### 7. 미출석 알림은 그다음에

처음부터 켜지 말 것. **2~3주 데이터가 맞는 걸 확인한 뒤**에 켠다. 잘못된
결석 알림이 학부모께 나가는 것이 이 기능에서 가장 큰 사고다.

지금 코드는 `syncLectureAttendance` 안에서 바로 알림을 보낸다. 처음
몇 주는 `notifyMissing` 호출을 주석 처리하거나 환경변수로 끄고 시작하는
편이 안전하다.

## 그다음 — 클리닉 출결까지 자동화 (원장님 요청)

키오스크는 학생들이 오래 써와서 이미 자리잡았다. 강의가 잘 돌면 **클리닉
출결도 굳이 조교가 안 눌러도 되게** 넓힌다.

준비는 이미 되어 있다.

- `attendance_records.source` 칸을 미리 넣어뒀다(`'manual' | 'macgai7'`).
  아직 코드가 쓰지 않는다.
- `lectureAttendance.ts`의 `fillClinicFromKiosk`가 이미 "같은 날 클리닉도
  있는 학생"의 클리닉 출결을 채우고 있다. 지금은 강의 날에만 돈다.

넓힐 때 할 일:

1. 크론 스케줄을 주말에서 매일로 (`.github/workflows/lecture-attendance.yml`)
2. 클리닉만 있는 날도 명단을 만들어 미출석을 잡도록 확장
3. 기록할 때 `source: 'macgai7'`를 같이 쓰고, **매일 도는 동기화가 조교가
   고쳐둔 것(`source='manual'`)을 되돌리지 않게** 할 것

> `marked_by`(조교 id)로 구분하면 되지 않나 싶지만, 그 칸은 조교가 누른 게
> 아닐 때 전부 null이라 "키오스크가 찍은 것"과 "시스템이 짐작으로 찍은 자동
> 지각"을 못 가른다. 그래서 `source`를 따로 뒀다.

**조교 수동 버튼은 없애지 말 것.** 학생이 깜빡 안 찍는 날은 반드시 생긴다.

## 이 방식의 약점 (알고 시작할 것)

맥가이7은 API를 제공하지 않는다(업체 확인, 2026-08). 다만 자동 접속을
금지한다고 하지도 않았다. 그래서 화면을 읽어오는 방식인데 —

**맥가이7이 화면을 개편하면 조용히 멈춘다.** 그래서 `macgai_sync_log`와
3시간 감시 알림을 같이 만들어 뒀다. 반드시 함께 쓸 것. 가끔 손봐야 하는
기능이라는 점을 원장님도 알고 계신다.
