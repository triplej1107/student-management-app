# 앱이 갑자기 안 될 때

2026-08-07에 실제로 겪은 일을 정리해둔다. 환경변수를 잘못 건드려 프로덕션이
멈췄고, 원인을 찾는 데 시간이 걸렸다. 다음엔 5분 안에 끝내자.

## 먼저 — 데이터는 안전하다

환경변수는 **출입증**이다. 잘못 넣어도 DB 안의 학생·출결·성적은 손상되지
않는다. 되돌리는 방법도 "원래 값을 다시 넣는 것"뿐이다. 복구 작업 같은 건
없다.

## 화면에 뜨는 문구로 원인 가리기

| 화면 문구 | 뜻 |
|---|---|
| `로그인 중 오류가 발생했어요` | **DB 조회 자체가 실패.** 키/URL 문제다 |
| `비밀번호가 올바르지 않습니다` | 진짜로 비밀번호가 틀린 것. 앱은 멀쩡하다 |
| 화면이 아예 안 뜸(500) | 환경변수가 **없는** 것(이름이 틀렸거나 미등록) |

`로그인 중 오류가 발생했어요`는 `src/lib/auth.ts`에서 Supabase 조회가
실패했을 때만 나온다. 이 문구가 보이면 비밀번호를 아무리 다시 쳐도 소용없다.

## 진짜 원인 보는 법

Vercel → **Logs** (또는 Observability → Logs) → 로그인을 한 번 더 시도 →
방금 찍힌 빨간 줄을 펼친다.

| 로그 문구 | 원인 |
|---|---|
| `Invalid API key` | 키가 **다른 프로젝트** 것 |
| `No API key found` | 환경변수 **이름**이 안 맞음 |
| `JWT expired` / `signature` | 옛날 방식 키가 만료·손상 |
| `fetch failed` / `ENOTFOUND` | `SUPABASE_URL`이 잘못됨 |

## 올바른 값 확인하기

**Supabase 프로젝트는 하나뿐이다.** 주소창에 이 식별자가 들어 있어야 그
프로젝트다.

```
mgncqumfpshbbaelnmtd
```

- `SUPABASE_URL` = `https://mgncqumfpshbbaelnmtd.supabase.co`
- `SUPABASE_SERVICE_ROLE_KEY` = 그 프로젝트의 **service_role**(또는 새 방식
  **Secret key**). `anon` / `publishable` 키가 아니다.

> Supabase가 키 체계를 바꾸는 중이라 화면에 옛날 키(`eyJ...`)와 새 키
> (`sb_secret_...`)가 같이 보인다. **둘 다 동작한다.** 급할 때는 원래 쓰던
> 종류로 되돌리는 게 가장 확실하다.

## 고치는 순서 (Vercel)

1. Settings → **Environment Variables** → 해당 변수 Edit
2. 값 교체 — **Production**에 체크돼 있는지 반드시 확인
3. **Deployments → 맨 위 → ⋯ → Redeploy**
   - 환경변수만 고치면 **이미 돌고 있는 배포에는 반영되지 않는다.** 이걸
     빼먹어서 "고쳤는데 왜 안 되지"가 나온다.
4. 1~2분 뒤 `kaujm.vercel.app`에서 확인

## 값 붙여넣을 때 주의

- Supabase는 키를 가려서 보여준다. **눈 아이콘으로 Reveal하거나 복사 버튼**을
  쓸 것. 가려진 상태를 드래그하면 점(●)만 복사된다.
- PowerShell 파이프(`"값" | npx vercel env add`)는 BOM이 섞여 값이 오염된다.
  화면에서 직접 붙여넣거나, Bash에서 `echo -n`을 쓸 것.

## 키가 새어 나갔을 때만 재발급

`service_role` / `sb_secret_` 키는 그 프로젝트 DB를 전부 읽고 쓸 수 있다.
다만 **아래에 해당할 때만** 급하게 갈면 된다.

- 깃허브에 **커밋**됐다 (공개 저장소면 몇 분 안에 봇이 긁어간다)
- 카톡·메일·슬랙으로 **보냈다**
- 화면 공유나 스크린샷에 **값이 그대로 찍혔다**

Vercel 환경변수끼리 잘못 옮겨 담은 정도는 계정 소유자만 볼 수 있는 곳이라
실질적 위험이 거의 없다. 불안하면 갈아도 되지만 급한 일은 아니다.

## 참고

- 이 레포는 `.env*`가 `.gitignore`에 걸려 있어 키가 커밋될 일이 없다
  (2026-08-07 깃 기록 전체를 훑어 확인함).
- 시크릿을 새로 추가하면 **세 곳 모두** 등록해야 한다 — `.env.local`,
  Vercel production, claude.ai/code "Default" 환경.
