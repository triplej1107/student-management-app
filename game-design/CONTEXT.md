# 슬라임 게임 프로젝트 — 세션 핸드오프 문서

어느 컴퓨터의 Claude 세션이든 이 문서를 읽으면 프로젝트를 이어받을 수 있다.
최종 갱신: 2026-08-02. 목표: **2026-08-22 (2학기 개강) v1 배포.**

## 프로젝트 개요

유종의미 국어학원 학생관리 앱(이 저장소)에 넣을 '슬라임 키우기' 게임.
**앱과 분리해 이 폴더에서 설계·디자인을 완성한 뒤 통합하는 방침.**

목적 3개: ① 학구열 고취(XP) ② UJC 소모(뽑기) ③ 인스타 자랑(학원 홍보).

## 확정된 핵심 설계

- **속성**: 오행 5속성 (화=열정/수=꾸준/목=암기/금=논리/토=끈기). 배틀 상성(상극 오각형, 우위 데미지 ×1.2)에도 사용.
- **시즌제**: 매년 3월 1일 전원 강제 환생. 세대↑ = 상위 직업 트리 해금 (1세대=1차 직업, 2세대=상위, 3세대=전설). 재원 학기 게이트 + 근속 XP 배율(+10%/학기, 최대 +50%). 재원 기준일 = `students.first_lesson_date`(0029). **"잘하는 학생보다 오래 다닌 학생이 즐기는 게임"이 원장 철학.**
- **성장**: 알(미스터리, 속성 비공개) → 부화 150XP → 틴 1,200 → 각성 3,500 → 전직 8,000 (시즌0은 전직 6,000). 시즌0 = 2026-08-22 ~ 2027-02-28.
- **XP**: 기존 테이블(attendance_records, clinic_checks) 기반 자동 부여만. 출석 50/지각 20/조정 30, 숙제 슬롯당 10(+7/7 보너스 30), 테스트 회당 최대 15, 향상 보너스 20, 스트릭 2주 ×1.1 4주 ×1.25. 배틀 승리로 XP 없음. 수동 XP 없음. `xp_events`에 source_key 멱등 기록.
- **UJC 경제**: ⚠️ 2026-08-02 심야에 전면 재설계됨 — 아래 "가챠 경제 재설계" 절이 최신. (구안: 주당 1개 적립, 뽑기 1회=1 UJC, 조각 10=뽑기권 1)
- **배틀**: 9월 말 2차 업데이트로 분리. 공식·승률 튜닝값은 설계-아이템카탈로그.md §2 참고. 비동기 자동, 하루 3판, 리더보드는 opt-in.
- **아이템**: 콘셉트 세트 시스템 (설계-아이템카탈로그.md §2.5) — 검사/농부/원시인/광부/마법사/군인/해적/닌자/술사. 3부위 세트효과 공+1 방+1. 눈 슬롯은 치장 전용(스탯 없음). **IP 주의: 루피·나루토·고죠 등 실존 캐릭터명·고유 디자인 금지, 장르 원형으로 재해석** (인스타 공개 전제).

## 디자인 (확정 스펙 v3 = slime-design.v3.json)

- 리부트 이력: v1·v2(물방울 실루엣+애니메 눈)는 폐기. v3 = 낮고 둥근 만두 몸통 + 줄기 끝 방울 꼭지(틴부터 속성 모양: 불꽃/물방울/잎/별/돌), **얼굴 미니멀(세로선 눈), 스타일 픽셀**.
- `슬라임랩.html` = 파라메트릭 디자인 도구 (브라우저로 열기만 하면 됨). 단계 4(알/베이비/틴/각성) × 얼굴 3 × 스타일 5 지원. 도트 장비 스프라이트 내장. 기본값 = v3 확정 스펙.
- 원장이 랩에서 튜닝 후 "디자인 값 JSON 복사"로 넘겨주면 v4로 저장하는 흐름.

# 🔴 가챠 경제 재설계 (2026-08-02 심야 — 최신 결론, 구현 전)

## 왜 재설계했나

원장이 v4 아이템 카탈로그(레전더리 5세트/에픽 11세트/레어 15/매직 15, 각 5부위 = 총 200종+)를 제시.
시뮬레이션 결과 **기존 경제(주 1 UJC, 1 UJC = 1뽑)로는 에픽 세트 완성이 수학적으로 불가능**함이 확인됨:

- 1년에 뽑기 56회 → 에픽 등급 자체가 연 2.2회만 등장. 세트(5부위) 완성엔 평균 11.4회 등장 필요.
- 확률을 24%까지(=에픽이 아니게 됨) 올려도, 아이템 종류를 1세트로 줄여도, UJC 배율 10배를 줘도 **완성률 0~3%**.
- 근본 원인: **뽑기 총량 부족**(상용 게임 대비 1/20) + **부위별 수집 구조**(필요 시행 11.4배). 곱하면 220배 격차.

## 확정된 새 구조 (원장 아이디어 + 시뮬 검증 완료)

### 1) UJC 10배 뻥튀기
- **기존 보유 UJC × 10 일괄 전환** (25개 → 250개). 지금까지의 클리닉 점검표 적립분도 ×10 소급.
- **클리닉 주간 완벽 수행 = 10 UJC** (기존 1 → 10)
- **원장·조교 재량 지급 가능** — 조교는 주 10개 한도. 좋은 질문/좋은 대답 등에 1~2개씩 자유롭게.
- **집공부 인증 → 추가 UJC** (인증 방식 미정 — 원장 결정 필요)
- 목적: 1 UJC를 "잘했어" 토큰 단위로 만들어 재량 지급이 가능해짐

### 2) 뽑기 상품 (묶음 보너스)
| 상품 | 내용 |
|---|---|
| 1 UJC | 1뽑 |
| 10 UJC | **11뽑** |
| 100 UJC | **120뽑 + 에픽 파츠 1개 확정(선택권)** |

⚠️ **100연뽑 확정 파츠는 반드시 '에픽'이어야 함.** 시뮬 결과 레전더리로 하면 연말에 레전더리 세트 45%, 1년이면 100% 완성 → "1년 반의 최종 보상" 지위가 붕괴됨.

### 3) 아이템이 나오고, 중복은 자동 분해 → 조각
(조각이 직접 나오면 뽑는 재미가 없다는 원장 지적 반영. 상용 게임 표준 문법)
- 뽑기 결과는 **항상 실물 아이템** (이름+그림). 등급별 연출 차등.
- **새 아이템** → 인벤토리 (바로 착용) / **중복** → 자동 분해되어 조각
- 인벤토리에서 **수동 분해도 가능** (안 쓰는 아이템 정리)

| 등급 | 분해 시 조각 |
|---|---|
| 일반 | 1 |
| 매직 | 1 |
| 레어 | 3 |
| **에픽** | **20** |
| **레전더리** | **100** |

### 4) 조각 상점 — 원하는 부위 지정 구매
(세트 통째 교환은 폐기 — 완성 전까지 후줄근하고 믹스매치 재미가 죽는다는 원장 지적)

| 부위 | 조각 |
|---|---|
| 매직 | 10 |
| 레어 | 30 |
| **에픽** | **100** |
| 레전더리 | 500 |

→ **레전더리 분해(100) = 에픽 부위 1개 구매**. 한 등급 위를 갈면 아래 등급 하나를 살 수 있는 계층 유지.

### 5) 등급 확률 (변경 없음)
일반 50% · 매직 30% · 레어 15% · 에픽 4% · 레전더리 1% · **20회 천장**
