# 슬라임 게임 프로젝트 — 세션 핸드오프 문서

어느 컴퓨터의 Claude 세션이든 이 문서를 읽으면 프로젝트를 이어받을 수 있다.
최종 갱신: 2026-08-03. 목표: **2026-08-22 (2학기 개강) v1 배포.**

## 프로젝트 개요

유종의미 국어학원 학생관리 앱(이 저장소)에 넣을 '슬라임 키우기' 게임.
**앱과 분리해 이 폴더에서 설계·디자인을 완성한 뒤 통합하는 방침.**

목적 3개: ① 학구열 고취(XP) ② UJC 소모(뽑기) ③ 인스타 자랑(학원 홍보).

## 확정된 핵심 설계

- **속성**: 오행 5속성 (화=열정/수=꾸준/목=암기/금=논리/토=끈기). 배틀 상성(상극 오각형, 우위 데미지 ×1.2)에도 사용.
- **시즌제**: 매년 3월 1일 전원 강제 환생. 세대↑ = 상위 직업 트리 해금 (1세대=1차 직업, 2세대=상위, 3세대=전설). 재원 학기 게이트 + 근속 XP 배율(+10%/학기, 최대 +50%). 재원 기준일 = `students.first_lesson_date`(0029). **"잘하는 학생보다 오래 다닌 학생이 즐기는 게임"이 원장 철학.**
- **성장**: 알(미스터리, 속성 비공개) → 부화 150XP → 틴 1,200 → 각성 3,500 → 전직 8,000 (시즌0은 전직 6,000). 시즌0 = 2026-08-22 ~ 2027-02-28.
- **XP**: 기존 테이블(attendance_records, clinic_checks) 기반 자동 부여만. 출석 50/지각 20/조정 30, 숙제 슬롯당 10(+7/7 보너스 30), 테스트 회당 최대 15, 향상 보너스 20, 스트릭 2주 ×1.1 4주 ×1.25. 배틀 승리로 XP 없음. 수동 XP 없음. `xp_events`에 source_key 멱등 기록.
- **UJC 경제**: ✅ 2026-08-03 최종 확정 — 아래 "가챠 경제 확정" 절이 유일한 기준. (08-02 심야안의 조각표·20회 천장·120뽑은 폐기됨)
- **배틀**: 9월 말 2차 업데이트로 분리. 공식·승률 튜닝값은 설계-아이템카탈로그.md §2 참고. 비동기 자동, 하루 3판, 리더보드는 opt-in.
- **아이템**: 콘셉트 세트 시스템 (설계-아이템카탈로그.md §2.5) — 검사/농부/원시인/광부/마법사/군인/해적/닌자/술사. 3부위 세트효과 공+1 방+1. 눈 슬롯은 치장 전용(스탯 없음). **IP 주의: 루피·나루토·고죠 등 실존 캐릭터명·고유 디자인 금지, 장르 원형으로 재해석** (인스타 공개 전제).

## 1) UJC — 10배 전환 유지

- **기존 보유 UJC × 10 일괄 전환** (25 → 250). 클리닉 적립분 소급.
- **클리닉 주간 완벽 수행 = 주 10 UJC** (기존 1 → 10)
- **추가 획득처 목표: 주 +5 수준** (시뮬 근거 — +10 넘으면 신입이 한 학기에 다 따라잡아 근속 우위 소멸):
  질문 게시판 공개 재량 지급(원장·조교, 조교 주 10개 한도) 1~2 / 클리닉 테스트 만점 회당 1 /
  2주 연속 만점 +2·3주 연속 +3 / 2배 이벤트(숙제 밀리는 기간·방학 특강) 연 3~4회.
- 집공부 인증 UJC는 **미정** (인증 방식 원장 결정 대기).

## 2) 뽑기 상품 — 1 UJC = 1뽑 유지 (직관적 교환가치가 우선이라는 원장 결정)

- 일반 50% · 매직 30% · 레어 15% · 에픽 4% · 레전더리 1% (변경 없음)

## 4) 조각 — 등급별 분리 (단일 조각 폐기)

- 뽑기 결과는 항상 실물 아이템. **중복 1개 → 그 등급 조각 1개** 자동 분해. 수동 분해 가능.
- **조각 상점: 같은 등급 조각 3개 = 그 등급의 원하는 부위 1개** 지정 구매.
- **환전: 상위 등급 조각 1개 → 하위 등급 조각 3개** (역방향 불가).
  → 레전더리 중복 1개 = 에픽 조각 3개 = 에픽 부위 1개 (원장 요구 조건 자동 성립).
- 조각→뽑기권 자동 전환(구 0034)은 제거.

- 노말 순화 3종 (총→물총, 칼→목검, 펜→만년필) 승인 여부 — 카탈로그 v5 참고

## 참고: 폐기된 대안들 (다시 논의하지 말 것)

- ❌ 아이템 종류 줄이기만으로 해결 → 종류 수는 병목이 아님 (v4에서 검증)
- ❌ 에픽 확률만 올리기 → 24%까지 올려야 하는데 그럼 에픽이 아니게 됨
- ❌ 세트 통째 교환 → 완성 전까지 빈손, 믹스매치 재미 소멸
- ❌ 조각이 뽑기에서 직접 나오기 → 박스 열었는데 조각이면 재미없음
- ❌ 100연뽑 확정 레전더리 → 레전더리가 너무 흔해짐
- ❌ 뽑기 3 UJC/회 인상 → 교환가치가 어색함 (원장). 1 UJC=1뽑 + 천장 100회로 해결
- ❌ 20회 천장 → 천장만으로 에픽 24회/년 확정 = 과잉 공급의 주범
- ❌ 업데이트 시 단일 풀 누적 → 2년차 신입 완성률 6%로 붕괴. 픽업 교체가 정답
- ❌ 배틀 코인 베팅 → 상심·패작·부익부·도박 프레임. 참가 보상제로 대체
