# items — 게임에 들어가는 아이템 원본

| 파일 | 무엇 |
|---|---|
| `items.json` | 매니페스트. 코드·부위·등급·**앵커**·기울기 (규격서 §4) |
| `{code}_{stage}.png` | 한 칸이 1픽셀인 도트 원본 |
| `노말-도트.mjs` | 노말 파츠 19종의 도트를 그리는 코드 (단계별 크기는 비율로 계산) |
| `노말-내보내기.mjs` | 위 도트를 PNG + items.json 으로 내보낸다. **앵커도 여기서 계산한다** |
| `노말-확인.mjs` | 랩의 진짜 렌더러에 물려 슬라임에게 입힌 그림을 뽑는다 (앵커 검증) |
| `노말-착용확인.png` | 그 결과 |
| `붙여넣은값-PNG로.mjs` | 랩에서 복사한 값을 PNG + items.json 으로 되푸는 도구 |

|---|---|---|
| 랩에서 반입 (GPT 그림) | 14 (머리 6 · 얼굴 6 · 오른손 2) | **없음** — 아래 참고 |
| 스크립트 생성 | 19 (얼굴 1 · 오른손 8 · 왼손 10) | 57장 있음 |

앞의 14종은 앵커만 있고 그림이 없다. 랩의 「담기」가 PNG 를 내려받게 되어 있는데
**아티팩트는 액자(iframe) 안이라 자동 내려받기가 조용히 막혔다.** 담긴 값은 브라우저에
남아 있었고 그걸 복사해 앵커를 살렸다. 지금은 담을 때 그림도 같이 저장한다.

## 스크립트로 만드는 방식 (19종)

랩을 **거치지 않는다.** 그림도 앵커도 코드가 만든다.

```
node game-design/items/노말-내보내기.mjs      # PNG 57장 + items.json 갱신
node game-design/items/노말-확인.mjs teen     # 입힌 그림으로 눈 확인 (baby/teen/awake)
```

앵커 규칙은 `슬라임랩-v4.html` 의 `autoAnchor` 를 그대로 옮긴 것이라 랩에서 반입한 것과
같은 자리에 놓인다. 손 슬롯의 「쥐는 높이」만 물건마다 다르므로 `노말-내보내기.mjs` 의
`GRIP` 에 적어 둔다 — 가방류는 손잡이(6~10%), 판·책은 가운데(45%), 오른손은 78%.

기울기(`ROT`)는 그림이 아니라 **놓을 때 주는 배치값**이다. 칼 12° · 총 8° · 나뭇가지 10° · 지팡이 6°.

아트를 고치려면 `노말-도트.mjs` 의 해당 함수만 고치고 내보내기를 다시 돌린다. 전부 재현된다.

## 랩에서 반입한 것의 PNG 를 채우는 법 (앞의 14종)

1. 랩에서 원본을 다시 반입하고 **「이 아이템 담기」** (이제 그림도 같이 저장된다)
2. **「전부 복사 (그림까지)」** 를 눌러 값을 통째로 얻는다
3. 그 값을 `dump.json` 으로 저장하고:

```
node 붙여넣은값-PNG로.mjs dump.json . items.json
```

세 번째 인자가 핵심이다 — **앵커와 기울기는 지금 `items.json` 것을 그대로 쓴다.**
다시 반입하면 앵커가 자동값으로 돌아가는데, 눈으로 맞춘 수고를 잃지 않으려는 것이다.

> 브라우저에서 `슬라임랩-v4.html` 을 직접 열면 내려받기가 정상 작동한다.
