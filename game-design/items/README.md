# items — 게임에 들어가는 아이템 원본

| 파일 | 무엇 |
|---|---|
| `items.json` | 매니페스트. 코드·부위·등급·**앵커**·기울기 (규격서 §4) |
| `{code}_{stage}.png` | 한 칸이 1픽셀인 도트 원본. 아직 없다 (아래 참고) |
| `붙여넣은값-PNG로.mjs` | 랩에서 복사한 값을 PNG + items.json 으로 되푸는 도구 |

## 지금 상태 (2026-08-05)

**앵커는 다 있고 PNG 가 없다.** 14종 42장이 필요하다.

랩의 「이 아이템 담기」가 PNG 를 내려받게 되어 있는데, **아티팩트는 액자(iframe)
안이라 자동 내려받기가 조용히 막힌다.** 담긴 값은 브라우저에 멀쩡히 남아 있었고
그걸 복사해 받아 이 `items.json` 을 만들었다 — 눈으로 맞춘 앵커와 기울기가 여기 있다.
다만 그림(픽셀)은 그때 저장 대상이 아니어서 없다. 지금은 담을 때 그림도 같이 저장한다.

담긴 것 — 머리 6 · 얼굴 6 · 오른손 2. 기울기는 연필 14° · 볼펜 9°.

## PNG 를 채우는 법

1. 랩에서 원본을 다시 반입하고 **「이 아이템 담기」** (이제 그림도 같이 저장된다)
2. **「전부 복사 (그림까지)」** 를 눌러 값을 통째로 얻는다
3. 그 값을 `dump.json` 으로 저장하고:

```
node 붙여넣은값-PNG로.mjs dump.json . items.json
```

세 번째 인자가 핵심이다 — **앵커와 기울기는 지금 `items.json` 것을 그대로 쓴다.**
다시 반입하면 앵커가 자동값으로 돌아가는데, 눈으로 맞춘 수고를 잃지 않으려는 것이다.
그림만 새로 받고 위치는 지킨다.

> 브라우저에서 `game-design/슬라임랩-v4.html` 을 직접 열면 내려받기가 정상 작동한다.
> 그 경우 담을 때마다 PNG 가 바로 떨어지므로 위 과정이 필요 없다.
