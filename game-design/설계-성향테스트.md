# 슬라임 성향 테스트 — 문항·판정·결과 설계 v1

2026-08-02 초안. 8문항 × 5선택지(속성당 1개), 정답 없음. 첫 로그인 시 1회,
이후 매년 3월 환생 때 재응시. 결과는 부화 전까지 비공개(미스터리 알).

## 판정 규칙

- 각 선택지는 오행 속성 1개에 +1점. 8문항이라 속성별 최대 8점.
- 최고점 속성이 슬라임 속성이 된다.
- **동점 처리**: 동점 속성 중 `hash(student_code + season_key) % n`으로 결정.
  학생마다 결과가 달라 랜덤처럼 느껴지지만 재현 가능(새로고침해도 같은 결과).
- 5속성 점수 전체를 저장한다 → 학부모 리포트, 환생 시 "작년의 나 vs 올해의 나" 비교에 사용.
- 선택지 순서는 문항마다 섞어서 배치(아래 표기 순서대로 내지 말 것 — 같은 속성이
  항상 같은 자리면 패턴이 노출됨). 문항별 표시 순서는 아래에 지정해둠.

## 문항 (8문항)

표기: [화]=열정·몰입 [수]=꾸준·루틴 [목]=성실·암기 [금]=논리·분석 [토]=끈기·오답

### Q1. 시험 4주 전, 공부를 시작하는 내 모습은?  (표시 순서: 금·토·화·목·수)
- [화] 발등에 불이 붙으면 무섭게 몰아친다. 짧고 굵게!
- [수] 특별할 것 없다. 하던 대로 매일 할 일을 한다.
- [목] 일단 외울 것부터 정리한다. 기본부터 차곡차곡.
- [금] 전체 범위를 훑고 계획표부터 짠다.
- [토] 지난 시험에서 틀렸던 부분부터 다시 본다.

### Q2. 국어 공부에서 가장 짜릿한 순간은?  (표시 순서: 화·금·수·토·목)
- [화] 문학 작품에 빠져들어 인물의 감정이 그대로 느껴질 때
- [수] 매일 풀던 지문이 어느 날 술술 읽힐 때
- [목] 외운 문법 개념이 문제에 딱 맞아떨어질 때
- [금] 비문학 지문의 구조가 한눈에 보일 때
- [토] 예전에 틀렸던 유형을 다시 만나 이번엔 맞혔을 때

### Q3. 숙제를 하는 내 스타일은?  (표시 순서: 수·목·금·화·토)
- [화] 한 번 앉으면 끝까지 한다. 앉기까지가 문제일 뿐.
- [수] 요일별로 나눠서 정해진 양만큼 한다.
- [목] 시키는 건 빠짐없이 다 한다. 밀리는 게 제일 싫다.
- [금] 이 숙제를 왜 내줬는지부터 생각해본다.
- [토] 틀린 문제 다시 풀기가 숙제의 핵심이라고 생각한다.

### Q4. 시험을 망쳤다. 나의 반응은?  (표시 순서: 토·수·금·목·화)
- [화] 분해서 잠이 안 온다. 다음엔 두고 보자.
- [수] 아쉽지만 페이스는 유지한다. 다음 시험도 있으니까.
- [목] 몰랐던 개념부터 다시 정리하고 외운다.
- [금] 채점표를 펴고 어디서 왜 틀렸는지 분석부터 한다.
- [토] 틀린 문제를 전부 오답노트에 옮기고, 두 번은 안 틀린다.

### Q5. 외워야 할 게 생겼을 때 나는?  (표시 순서: 목·화·토·수·금)
- [화] 집중 잘 되는 날을 잡아 한 번에 왕창 외운다.
- [수] 며칠에 걸쳐 조금씩 나눠 외운다.
- [목] 쓰면서 외운다. 손이 기억할 때까지.
- [금] 원리나 이야기로 연결해서 이해로 외운다.
- [토] 외웠는지 스스로 테스트해보고, 틀린 것만 다시 외운다.

### Q6. 공부가 제일 잘 되는 순간은?  (표시 순서: 금·수·화·토·목)
- [화] 마감이 코앞일 때. 심장이 뛰면 머리가 돌아간다.
- [수] 매일 같은 시간, 같은 자리에 앉았을 때.
- [목] 오늘 할 분량이 명확히 정해져 있을 때.
- [금] 조용한 곳에서 혼자 생각을 정리할 때.
- [토] 어제 하다 만 부분을 이어서 할 때.

### Q7. 어려운 문제가 안 풀릴 때 나는?  (표시 순서: 화·토·목·금·수)
- [화] 오기가 생겨서 풀릴 때까지 붙잡는다.
- [수] 일단 넘어가고 나중에 다시 본다. 페이스가 무너지면 안 되니까.
- [목] 비슷한 기본 문제부터 다시 풀어본다.
- [금] 문제가 요구하는 걸 조건별로 쪼개본다.
- [토] 해설을 본 다음, 며칠 뒤에 반드시 다시 푼다.

### Q8. 나에게 '공부를 잘한다'는 것은?  (표시 순서: 수·금·토·화·목)
- [화] 하고 싶을 때 무섭게 몰입할 수 있는 것
- [수] 흔들리지 않고 매일 하는 것
- [목] 기본을 빠짐없이 쌓아두는 것
- [금] 원리를 이해해서 처음 보는 문제도 푸는 것
- [토] 같은 실수를 반복하지 않는 것

## 결과지 카피 (부화 시 공개)

각 결과지는 ① 캐치프레이즈 ② 강점 3 ③ 조심할 점 2 ④ 국어 코칭 2 로 구성.
학부모에게 보여줘도 "학습 성향 진단"으로 읽히는 톤 유지.

### 화 · 불티 슬라임 — "타오를 때 무서운 몰입형"
- 강점: 폭발적인 집중력 / 감정 이입 능력(문학에 유리) / 승부욕
- 조심: 시동이 늦게 걸림 / 페이스 유지가 약함
- 코칭: 몰입 스위치가 켜지는 조건(시간·장소)을 찾아 고정하기.
  실제 시험 1주 전을 '나만의 마감일'로 당겨서 점화 타이밍을 앞으로.

### 수 · 이슬 슬라임 — "매일 조금씩, 복리로 크는 루틴형"
- 강점: 꾸준함 / 안정적인 페이스 / 슬럼프 회복력
- 조심: 단기 폭발력 부족 / 갑작스러운 변화에 약함
- 코칭: 루틴에 주 1회 '고난도 도전 슬롯'을 넣어 상한선 끌어올리기.
  시험 직전 2주는 평소 루틴의 1.5배로 증량.

### 목 · 새싹 슬라임 — "기본기를 차곡차곡 쌓는 성실형"
- 강점: 성실함 / 암기력 / 개념 정확도(문법에 유리)
- 조심: 응용·추론 문제에서 당황 / 외운 것에서 벗어나면 흔들림
- 코칭: 외운 다음 "왜?"를 한 번씩 묻는 습관으로 이해를 덧대기.
  기출 변형 문제로 응용 내성 기르기.

### 금 · 별빛 슬라임 — "구조가 보이는 논리 분석형"
- 강점: 독해 구조화 / 원리 이해(비문학에 유리) / 계획 수립
- 조심: 이해 안 되면 암기를 미룸 / 완벽주의로 진도가 느려짐
- 코칭: '일단 외우고 이해는 나중에' 허용 목록 만들기.
  문학은 분석보다 감상 훈련을 의식적으로 병행.

### 토 · 바위 슬라임 — "틀린 문제를 두 번 안 틀리는 끈기형"
- 강점: 복습력 / 오답 관리 / 장기전에 강함
- 조심: 새로운 유형 도전을 미루는 경향 / 진도 속도
- 코칭: 오답노트는 3회독 시스템(당일→3일 뒤→시험 전)으로.
  주 1회는 '새 유형 개척의 날'로 지정해 도전량 확보.

## 환생(3월) 재응시

- 같은 문항으로 재응시 → 새 속성 결정 (매년 3월 1일 전원).

  "작년: 화 4 · 토 2 → 올해: 토 5 · 화 2. 몰아치던 네가 끈질겨졌구나."
- 이 비교 리포트가 학부모 면담 자료가 된다.
