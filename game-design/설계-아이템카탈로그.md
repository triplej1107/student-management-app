| 왼손 | 방패·보조 | **방어** | 방패 외에 마법서·랜턴·자루 등 세트 보조구 |
| 머리 | 모자 | **방어** | |
| 눈 | 안경·안대 | **없음(치장)** | 원장 결정(2026-08-02): 눈 본연의 귀여움 보존 — 일부러 안 끼는 선택 존중 |

## 2. 슬라임 스탯 (장비 스탯은 공격·방어 2계열만)

| 스탯 | 기본값 | 장비 슬롯 | 배틀에서의 역할 |
|---|---|---|---|
| 체력 HP | 80 + 레벨×1.2 | (장비 없음 — 레벨·속성만) | 0 되면 패배 |
| 공격 ATK | 14 + 레벨×0.12 | 오른손 | 턴당 데미지 기본치 |
| 방어 DEF | 0 | 왼손, 머리 | 받는 데미지 감산 (최소 3 보장) |
| 치명 CRIT | 20% 고정 | (장비 없음 — 눈은 치장 전용) | 데미지 ×2 확률 |

**속성별 기본 보정**: 화 공격+1.5 / 수 체력+8 / 목 방어+1.5 / 금 치명+5%p / 토 방어+1·체력+4
**환생 세대 보너스**: 세대당 공격+1, 방어+1 (기확정).

**배틀 공식** (시뮬 튜닝 완료본): 턴당 데미지 = (공격+무기) × 상극우위1.2 ×
컨디션(0.75~1.25/판) × 랜덤(0.5~1.5), 치명 시 ×2, 받는 데미지 = max(3, 데미지−방어).
선공은 50:50 동전던지기(민첩 스탯 제외됨). 치명 장비 반영해 **구현 주간에
시뮬 재튜닝 필수** (동레벨 풀셋 vs 맨몸 승률 85% 이하 기준).

**등급별 장비 스탯**:

| 등급 | 공격(오른손) | 방어(왼손/머리, 각각) |
|---|---|---|
| 일반 | +1 | +1 |
| 매직 | +2 | +2 |
| 레어 | +3 | +3 |
| 유니크 | +4 | +4 |
| 레전더리 | +6 | +6 |

## 2.5 콘셉트 세트 시스템 (2026-08-02 원장 지시)

아이템을 등급 단품이 아니라 **직업·캐릭터 콘셉트 세트**(모자+오른손+왼손)로 구성한다.
**세트 효과: 3부위 완성 시 공격+1, 방어+1** — 같은 세트를 모으려는 뽑기 동기가 된다.

| 세트 | 등급 | 머리 | 오른손 | 왼손 | 비고 |
|---|---|---|---|---|---|
| 검사 | 일반~레전더리 | 투구류 | 검 라인(나무 검~성검 유종) | 방패 라인 | 기존 카탈로그 재편 |
| 농부 | 일반 | 밀짚모자 | 쇠스랑 | 곡물 자루 | |
| 원시인 | 매직 | 매머드 털모자 | 뼈다귀 몽둥이 | 통나무 방패 | |
| 광부 | 매직 | 헤드램프 안전모 | 곡괭이 | 랜턴 | |
| 마법사 | 레어 | 마법사 고깔 | 마법사 지팡이 | 마법서 | 랩에 구현 완료 |
| 군인 | 레어 | 철모 | 야전삽 | 위장 방패 | 총기는 학원 앱 특성상 제외 — 야전삽이 오히려 밈 파워 있음 |
| 해적 | 유니크 | 해적 삼각모 | 커틀러스 | 갈고리 | |
| 닌자 | 유니크 | 닌자 머리띠 | 쿠나이 | 대형 표창 | |
| 술사 | 레전더리 | (모자 없음) | 주술 지팡이 | 결계서 | 코어는 **검은 안대**(눈·치장) — 눈 슬롯이 주인공인 유일한 세트 |

**IP 주의 (v1 슬라임 때와 같은 이유)**: 원장이 예시로 든 루피·나루토·고죠 사토루는
실존 작품 캐릭터라 이름·고유 디자인을 그대로 쓰면 안 된다(인스타 공개 전제).
위처럼 **장르 원형**(해적/닌자/안대 술사)으로 재해석하고, 아이템·세트 이름에
캐릭터명은 쓰지 않는다. 학생들은 어차피 알아본다 — 그게 이 방식의 재미다.

**레전더리 아트 규칙 (2026-08-02 원장 지시 — "1%는 픽셀을 아끼지 말 것")**:
- 해상도 2배: 일반 아이템 셀 7px, **레전더리는 셀 3.5px** — 디테일 밀도가 눈에 띄게 다름
- **전용 이펙트 필수**: 세트 테마에 맞는 애니메이션 파티클 (성검=불꽃 춤,
  용비늘=잉걸불, 왕관=성광 반짝임. 이후: 뇌전=스파크, 얼음=서리 입자 등)
- 랩에 대표 3종(성검 유종·용비늘 방패·수석의 왕관) 구현 완료 — 이 톤이 기준

방어는 왼손+머리 이중 슬롯이라 총방어가 공격을 압도할 수 있음 → 시뮬에서
방어 풀셋이 너무 단단하면 방어만 -1씩 낮추는 것이 1순위 밸런스 패치.

## 4. 가챠 경제 — ⚠ 최신 앱 확인 후 전면 개편

최신 앱을 pull해서 확인한 사실: **UJC는 주당 1개 적립되고 10/20/30개를
5천/1.5만/2만원 기프티콘으로 교환하는 실물 가치 재화**다 (1 UJC ≈ 500원).
따라서 v1의 "뽑기 100 UJC" 설계는 폐기하고 아래로 교체한다.

- **뽑기 가격: 1회 1 UJC (실물가 약 500원 상당)** — 2026-08-02 원장 제안으로
  2→1 조정. 주당 적립(1 UJC)과 1:1이라 "클리닉 끝내면 그 주에 바로 뽑기"라는
  주간 습관 루프가 완성된다. 학생이 뽑기를 고르면 기프티콘 원가 500원이 굳으므로
  (목적 2 "UJC 소모"가 곧 비용 절감), 쌀수록 원장에게 유리한 구조.
- 1 UJC 조정의 파생 효과: 연간 뽑기 횟수가 정규 ~30회 + 뽑기권 ~15회 = 45회
  수준으로 늘어남 → **천장을 30회 → 20회로 하향** (30회면 시즌 내 발동이
  거의 불가능해 무의미). 풀 58종 기준 1시즌에 절반 수집 페이스로 적절.
- **게임은 UJC를 새로 발행하지 않는다.** UJC는 실물 가치가 있어서 게임
  보상으로 뿌리면 기프티콘 원가 부담이 커진다. 레벨업·주간 미션 보상은
  **뽑기권(무료 1회권)** 으로 지급 — 레벨업당 1장, 주간 미션(개근+숙제 7/7) 1장.
- **중복 아이템 → 조각 3개** (등급 무관). **조각 10개 = 뽑기권 1장** 교환.
  UJC 환급 없음 (발행 금지 원칙).
- 등급 확률: 일반50 / 매직30 / 레어15 / 유니크4 / 레전더리1 (%) — 유지
- 천장: 유니크 이상 미출현 **20회** 누적 시 확정 (1 UJC 조정에 맞춰 하향)
- v2 풀 58종(착용 40+배경 10+이펙트 8) 기준 레전더리 개별 확률 ≈ 0.1%
- 신규 아이템은 "시즌 컬렉션" 단위로 묶어 공지 → 뽑기 재유행 유도
