# 아이템 반입 규격 — 밖에서 만든 도트를 그대로 넣기

작성 2026-08-04. **다른 도구/AI 에서 아이템 도트를 그려 올 때 이 문서 하나만 주면 된다.**
이대로 지키면 손대지 않고 그대로 게임에 들어간다. 어기면 반입기가 잡아내서 되돌려 준다.

---

## 0. 한 장으로 요약

| | 값 |
|---|---|
| 형식 | **PNG, 배경 투명** |
| 해상도 | **이미지 1픽셀 = 게임 1칸.** 확대해서 주지 말 것 |
| 안티앨리어싱 | **금지.** 알파는 0 아니면 255만 |
| 색 수 | 아이템 하나당 **12색 이하** (투명 제외) |
| 크기 | 아래 §2 상한 이내 |
| 벌 수 | 아이템 하나당 **PNG 2장** (틴·각성 공용 1 + 베이비용 1) |
| 같이 줄 것 | `items.json` 매니페스트 (§4) |

가장 흔한 실패는 딱 하나다 — **이미지 생성 AI 는 기본으로 안티앨리어싱을 넣는다.**
경계가 흐려지면 픽셀 격자가 사라져서 몸통과 같이 놓을 수가 없다.
이 저장소는 이미 그 이유로 생성 이미지에서 코드 렌더로 되돌아온 적이 있다
(`디자인-계보.md` — 색 이어짐 길이가 1px 61% / 2px 12% / 3px 7% 로 흩어졌다).
**"픽셀 아트 스타일"로 그려달라고 하면 안 되고, "1픽셀 = 1픽셀, 안티앨리어싱 없이"** 라고 해야 한다.

---

## 1. 좌표계

몸통이 쓰는 좌표계 그대로다. 반입기가 앵커에 맞춰 놓아주므로 **절대 좌표는 신경 쓸 필요 없다.**

- viewBox `-96 -26 192 200`, 바닥선 y = 145, 격자 셀 = 3 단위
- 노말~레어는 셀 3 (몸과 같은 굵기), 에픽·레전더리만 셀 1.5 (두 배 촘촘)
- **이미지 1픽셀이 곧 1칸**이므로 PNG 안에서는 셀 크기를 몰라도 된다

## 2. 슬롯별 크기 상한 (칸 = PNG 픽셀)

틴 기준 실측값이다. 상한을 넘으면 얼굴을 덮거나 화면 밖으로 나간다.

| 슬롯 | 기준선에서 쓸 수 있는 폭 | 권장 PNG 크기 (가로 × 세로) | 상한 |
|---|---|---|---|
| 머리 | 32칸 | 34 × 16 | 40 × 20 |
| 얼굴 | 38칸 | 34 × 10 | 40 × 14 |
| 오른손 | — (몸 밖) | 12 × 26 | 18 × 34 |
| 왼손 | — (몸 밖) | 16 × 22 | 22 × 30 |
| 이펙트 | 몸 전체 | 60 × 20 | 70 × 26 |

- 머리는 챙처럼 옆으로 튀어나오는 부분까지 포함한 값이다. 모자 본체는 32칸 안에 들어와야 한다.
- 손은 몸 바깥에 놓이므로 폭보다 **세로 길이**가 중요하다. 30칸을 넘으면 머리 위로 솟는다.

## 3. 앵커 — 아이템이 몸에 붙는 점

**PNG 안에서 "이 픽셀이 몸에 닿는다"는 점 하나를 정해서 매니페스트에 적는다.**
반입기가 그 점을 슬롯 좌표에 겹쳐 놓는다. 좌표 원점은 PNG 왼쪽 위 (0,0).

| 슬롯 | 앵커로 잡을 곳 |
|---|---|
| 머리 | 모자 **아래 테두리의 가운데** (챙이 아니라 머리에 닿는 선) |
| 얼굴 | 안경 **두 알 사이 가운데**, 눈높이 |
| 오른손 | 손잡이를 **쥐는 자리** (연필이면 아래에서 1/4 지점) |
| 왼손 | 같음. 좌우 반전은 반입기가 하지 않으니 **왼손용으로 그려 줄 것** |
| 이펙트 | 발밑 가운데 |

참고 — 세 단계의 실제 앵커 좌표 (반입기가 알아서 쓴다):

| | 정수리 y | 머리선 y / 폭 | 눈높이 y / 폭 | 손 (x, y) |
|---|---|---|---|---|
| 베이비 | 96 | 108 / 22칸 | 129 / 26칸 | ±39, 138 |
| 틴 | 51 | 75 / 32칸 | 111 / 38칸 | ±51, 132 |
| 각성 | 45 | 72 / 34칸 | 108 / 40칸 | ±54, 132 |

## 4. 매니페스트 `items.json`

PNG 들과 같은 폴더에 둔다.

```json
{
  "cell": 3,
  "authoredFor": "teen",
  "items": [
    {
      "code": "nm_head_cap",
      "ko": "야구모자",
      "slot": "head",
      "tier": "normal",
      "png": "nm_head_cap.png",
      "anchor": [17, 13],
      "pngBaby": "nm_head_cap_baby.png",
      "anchorBaby": [12, 9]
    }
  ]
}
```

- `slot` = `head` | `face` | `right` | `left` | `fx`
- `tier` = `normal` | `magic` | `rare` | `epic` | `legendary`
- `anchor` = [x, y] PNG 픽셀 좌표
- `code` 규칙은 `아이템카탈로그-v5.md` 를 따른다 — 노말 `nm_{slot}_{이름}`, 세트템 `{set}_{slot}`

## 5. 왜 두 벌인가

한 벌만 그리면 베이비에서 아이템이 몸보다 커진다. 베이비 머리 폭은 22칸인데 틴은 32칸이라 **69%** 다.
도형이면 다시 스냅하면 되지만 **PNG 는 0.69배로 줄이면 픽셀이 깨진다.**

- **틴 · 각성 공용 1장** — 둘의 차이는 6% 라 같은 스프라이트로 충분하다. 반입기가 위치만 벌려 놓는다.
- **베이비용 1장** — 틴의 약 70% 크기로 **다시 그린다**(줄이는 게 아니라). 디테일은 덜어도 된다.
- 베이비는 노말만 착용하므로 베이비용은 **노말 33종만** 있으면 된다. 매직 이상은 한 장이면 끝.

## 6. 음영 문법 — 이걸 지켜야 몸통과 한 세계로 보인다

몸통이 볼록해 보이는 이유가 그대로 아이템에도 적용된다. 광원은 **좌상단** 하나뿐이다.

1. **1칸 어두운 외곽선** — 실루엣 전체를 두른다. 본색보다 어둡게(대략 ×0.55)
2. **본색** — 가운데
3. **위쪽 밝은 톤** — 좌상단 광원 쪽. 본색에서 흰색 방향으로 약 24%
4. **아래 그림자** — 아래 20% 높이. 본색 ×0.80
5. **흰 하이라이트 1~3칸** — 좌상단 모서리에 각지게. 둥글리지 말 것

> 색을 안 맞춰도 된다. **본색만 칠해서 주면 반입기가 1·3·4·5 를 자동으로 입힌다.**
> 그 편이 오히려 몸통과 정확히 같은 톤이 나온다. 직접 칠해 오면 그대로 존중한다.

## 7. 넘겨줄 때 이 문장을 그대로 쓰면 된다

> 픽셀 아트 아이템을 그려줘. **이미지 1픽셀이 게임의 1픽셀이다** — 확대하지 말고,
> 안티앨리어싱 없이, 알파는 0 또는 255만 써. 배경 투명 PNG.
> 크기는 가로 34 세로 16 픽셀 이내. 색은 12색 이하.
> 광원은 좌상단 하나. 실루엣 전체에 1픽셀 어두운 외곽선을 두르고,
> 위쪽은 밝은 톤, 아래 20%는 그림자, 좌상단에 흰 하이라이트 1~3픽셀을 각지게 넣어.
> 둥근 앤티앨리어싱된 가장자리는 절대 만들지 마.

## 8. 반입기가 잡아내는 것

랩의 **아이템 반입** 절에 PNG 를 떨구면 즉시 검사하고 세 단계에 얹어 보여준다.

- 알파가 0·255 가 아닌 픽셀 → **안티앨리어싱** (몇 개인지 알려준다)
- 색 수 초과
- 크기 상한 초과
- 앵커가 이미지 밖
- 통과하면 그 자리에서 베이비·틴·각성에 착용한 그림을 보여준다

검사에서 걸리면 **넣지 않는다.** 어중간하게 들어가서 나중에 103종을 다시 손대는 것보다 낫다.
