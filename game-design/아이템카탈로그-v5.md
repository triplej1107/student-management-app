## 슬롯·스탯 규칙

- 세트 5부위 = **머리 / 얼굴 / 오른손 / 왼손 / 이펙트**. 노말은 이펙트 없음(머리·얼굴·오른손·왼손만).
- 배경 슬롯은 v1 뽑기에서 **제외** (자랑하기 기능의 기본 배경으로 대체, 시즌1 후보).
- 스탯 부위는 **머리(방어)·오른손(공격)·왼손(방어)** 3개뿐. 얼굴·이펙트는 치장 전용.
- 등급 스탯: 노말 +1 / 매직 +2 / 레어 +3 / 에픽 +4 / 레전더리 +6 (공·방 동일).
- 세트효과: 스탯 3부위(머리+오른손+왼손) 동일 세트 착용 시 공+1 방+1. 5부위 완성은 도감 뱃지 + 자랑하기 전용 연출.
- 아이템 코드 규칙: 세트템 `{set}_{slot}` (slot = head/face/right/left/fx), 노말 `nm_{slot}_{이름}`.
- **아이템 격자**: 노말~레어는 몸과 같은 **셀 3**(도트 맛이 사는 굵기). 에픽·레전더리처럼
  디테일이 실제로 필요한 등급만 **셀 1.5**(2배 촘촘)로 내린다. 랩의 「아이템 픽셀 크기」
  슬라이더로 갈아 끼우며 비교한다 — 도형으로 그려 두어 격자만 바꾸면 통째로 다시 스냅된다.
- **레전더리 아트 규칙**: 셀 1.5 + 전용 애니메이션 이펙트 필수.

> **레전더리는 5세트를 만들어 두고 시즌0에는 2세트만 연다** (원장 2026-08-04).
> 나머지 3세트는 운영 캘린더의 9월 레전더리 픽업 교체분으로 대기시킨다
> (CONTEXT.md「운영 캘린더」). 뽑기 풀 크기는 늘 2세트 = 10종이므로 103종 합계는 그대로다.

## IP 주의 (전 세트 공통)

에픽·레전더리 라인은 인기 작품의 **장르 원형 재해석**이다. 캐릭터명·작품명·고유 로고를
이름이나 도트에 절대 쓰지 않는다 (인스타 공개 전제). 학생들은 어차피 알아본다 —
그게 재미다.

**디자인 근접도는 감수한다** (원장 판단 2026-08-04). 이름을 원형으로 지키는 선까지가
방침이고, 실루엣·색 조합이 특정 캐릭터를 떠올리게 하는 것까지는 문제 삼지 않는다.
동네 학원 앱 규모에서 감당할 수 있는 위험으로 본다. — 이 건은 결정났으니 다시 들추지 말 것.
