# 마이그레이션 적용 기록

SQL 마이그레이션을 Supabase SQL Editor에 직접 붙여넣어 실행하는 방식이라
자동으로 추적이 안 된다. 새 마이그레이션 파일을 추가했으면, 사용자가
SQL Editor에서 실행해 "성공했어" 확인해줄 때 이 파일에 한 줄 추가할 것
(파일명 + 확인한 날짜). 날짜를 모르는 과거 항목은 체크만 해둔다.
